# Инструкция по установке Fantasy Quest (для новичков)

## Шаг 1: Скачать Godot Engine

1. Перейди на сайт: **https://godotengine.org/download**
2. Нажми **"Godot Engine"** (НЕ "Godot Engine - .NET")
3. Скачай версию для своей системы (Windows / Mac / Linux)
4. Распакуй архив в любую папку
5. Запусти файл **Godot_v4.x.x-stable_win64.exe** (или аналог для Mac/Linux)

> Godot не требует установки! Просто распакуй и запусти.

## Шаг 2: Скачать проект

### Вариант А: Через GitHub
1. Перейди на страницу репозитория
2. Нажми зелёную кнопку **Code** → **Download ZIP**
3. Распакуй ZIP в любую папку

### Вариант Б: Через Git
```bash
git clone https://github.com/kalidarhan59-hub/newai.git
cd newai/godot-fantasy-rpg
```

## Шаг 3: Открыть проект в Godot

1. Запусти Godot Engine
2. В менеджере проектов нажми **"Import"** (Импорт)
3. Нажми **"Browse"** (Обзор) и найди файл `project.godot` в папке `godot-fantasy-rpg`
4. Нажми **"Import & Edit"**
5. Подожди пока Godot загрузит проект

## Шаг 4: Запустить игру

1. В Godot Engine нажми кнопку **▶** (Play) в правом верхнем углу
   - Или нажми клавишу **F5**
2. Откроется главное меню игры
3. Нажми **"Начать игру"**
4. Ты появишься в Деревне Надежды!

## Шаг 5: Как играть

### Управление
| Клавиша | Действие |
|---|---|
| **W A S D** или **Стрелки** | Двигаться |
| **Пробел** или **Левая кнопка мыши** | Атаковать |
| **Shift** | Рывок (уклонение) |
| **E** | Поговорить с НПС / Взаимодействие |
| **F** | Использовать зелье здоровья |
| **I** или **Tab** | Инвентарь |

### Начало игры
1. Поговори со **Старейшиной Ирвином** (в центре деревни) — он даст первый квест
2. Поговори с **Кузнецом Торином** — купи лучшее оружие/броню
3. Поговори с **Алхимиком Мирой** — купи зелья
4. Иди к **порталу "Тёмный Лес"** (вверху карты) — начни приключение!

### Советы
- Покупай зелья перед каждым приключением
- Убивай мобов для XP и золота
- Возвращайся в деревню, когда HP мало
- Боссы сильные — прокачайся и купи хорошую броню перед боем
- При смерти теряешь 10% золота

## Что делать если...

### Godot говорит "Could not load scene"
- Убедись что ты открыл папку `godot-fantasy-rpg`, а не корень репозитория
- Файл `project.godot` должен быть в корне открытой папки

### Игрок не двигается
- Проверь что нажал Play (F5), а не просто открыл сцену
- Убедись что играешь от **Village.tscn** (главное меню запускается автоматически)

### Нет текстур (всё белое/серое)
- Это нормально! Игра использует цветные прямоугольники вместо спрайтов
- Ты можешь добавить свои спрайты позже (замени Sprite2D в сценах)

### Нет звуков
- Звуки не добавлены — добавь свои через Godot (AudioStreamPlayer2D)

## Как добавить свои спрайты

1. Положи PNG-файлы в папку `res://` (например `res://sprites/player.png`)
2. Открой сцену (например `Player.tscn`)
3. Выбери узел **Sprite2D**
4. В **Inspector** справа найди поле **Texture**
5. Перетащи свой PNG в это поле
6. Готово!

## Структура файлов

```
godot-fantasy-rpg/
├── project.godot         ← Открыть этот файл в Godot
├── scenes/               ← Сцены (игрок, враги, уровни, UI)
├── scripts/              ← Скрипты (GDScript)
│   ├── systems/          ← Глобальные системы (GameData, EventBus)
│   ├── player/           ← Скрипт игрока
│   ├── enemies/          ← AI врагов
│   ├── bosses/           ← AI боссов
│   ├── npcs/             ← НПС
│   ├── weapons/          ← Снаряды
│   ├── items/            ← Предметы
│   ├── levels/           ← Генерация уровней
│   ├── ui/               ← Интерфейс
│   └── effects/          ← Визуальные эффекты
└── docs/                 ← Документация
```
