# Fantasy Quest — 2D Фэнтези RPG Приключение

2D ролевая игра с видом сверху на движке **Godot 4.2+**. Исследуй мир, сражайся с монстрами, побеждай боссов, покупай оружие и броню!

## Контент

### Оружие (20 видов)
| Тип | Оружие |
|---|---|
| Мечи (6) | Деревянный, Железный, Стальной, Огненный клинок, Клинок Тени, Святой Экскалибур |
| Топоры (3) | Ржавый, Боевой, Громовой |
| Кинжалы (3) | Ржавый кинжал, Клинок убийцы, Ядовитый клык |
| Луки (3) | Короткий, Охотника, Эльфийский |
| Посохи (4) | Ученика, Огня, Льда, Архимага |
| Молоты (2) | Каменный, Молот Дракона |

### Броня (15 видов)
- 4 шлема, 6 нагрудников, 4 щита, 3 пары сапог
- Редкости: Обычная → Необычная → Редкая → Эпическая → Легендарная

### Мобы (18 видов)
| Локация | Враги |
|---|---|
| Лес (1-5) | Слаймы (2), Гоблин, Гоблин-лучник, Волк, Трент |
| Пещера (6-12) | Летучая мышь, Скелет, Скелет-маг, Паук, Каменный голем |
| Замок (13-19) | Тёмный рыцарь, Тёмный маг, Горгулья, Вампир |
| Вулкан (20-25) | Огненный элементаль, Демон, Орк-военачальник |

### Боссы (5)
1. **Лесной Страж** (Ур.5) — Дроп: Ключ от пещеры
2. **Ледяной Голем** (Ур.12) — 3 фазы, замораживает
3. **Некромант** (Ур.19) — Призывает скелетов
4. **Великий Дракон Игнис** (Ур.25) — 4 фазы, финальный босс
5. **Тёмный Властелин** (Ур.25) — Секретный босс

### НПС (6)
- Старейшина Ирвин (квесты)
- Кузнец Торин (оружие, броня)
- Алхимик Мира (зелья)
- Маг Зефирон (посохи, магия)
- Воин Гарет (квесты)
- Таинственный незнакомец (квесты в пещере)

### Квесты (7)
- Спаси деревню, Охота на гоблинов, Ледяная угроза
- Тьма в замке, Пламя Дракона, Зачистка пещеры, Ядовитые пауки

### Локации (5)
1. Деревня Надежды (старт)
2. Тёмный Лес
3. Ледяная Пещера
4. Тёмный Замок
5. Вулкан Игниса

## Управление
| Клавиша | Действие |
|---|---|
| WASD / Стрелки | Движение |
| Пробел / ЛКМ | Атака |
| Shift | Рывок (dodge) |
| E | Взаимодействие (НПС, порталы) |
| F | Использовать зелье |
| I / Tab | Открыть инвентарь |
| Q, R | Навыки |

## Установка

Смотри [SETUP_GUIDE_RU.md](docs/SETUP_GUIDE_RU.md) — подробная инструкция для новичка.

**Быстрый старт:**
1. Скачай [Godot 4.2+](https://godotengine.org/download)
2. Открой проект через Godot (Import → выбери `project.godot`)
3. Нажми ▶ Play (F5)

## Структура проекта
```
godot-fantasy-rpg/
├── project.godot              # Настройки проекта
├── scenes/
│   ├── player/Player.tscn     # Сцена игрока
│   ├── enemies/Enemy.tscn     # Сцена врага
│   ├── bosses/Boss.tscn       # Сцена босса
│   ├── npcs/NPC.tscn          # Сцена НПС
│   ├── weapons/               # Снаряды
│   ├── items/ItemDrop.tscn    # Дроп предметов
│   ├── levels/                # 5 уровней
│   └── ui/                    # Меню, HUD, магазин, диалоги
├── scripts/
│   ├── systems/               # GameData, EventBus (глобальные)
│   ├── player/Player.gd       # Скрипт игрока
│   ├── enemies/Enemy.gd       # AI врагов
│   ├── bosses/Boss.gd         # AI боссов
│   ├── npcs/NPC.gd            # Логика НПС
│   ├── weapons/               # Снаряды
│   ├── items/ItemDrop.gd      # Подбор предметов
│   ├── levels/LevelGenerator.gd  # Генерация уровней
│   ├── ui/                    # Скрипты интерфейса
│   └── effects/               # Визуальные эффекты
└── docs/
    ├── GDD.md                 # Game Design Document
    └── SETUP_GUIDE_RU.md      # Инструкция по установке
```
